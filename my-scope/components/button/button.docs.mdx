# Button

The `Button` component is a reusable UI element for triggering actions.

## Usage

```tsx
import { Button } from './button';

<Button label="Click Me" onClick={() => alert('Button clicked!')} />;
```

## Variations

- **Basic Button**: A simple button with a label.
- **Button with Click**: A button that triggers an action.
- **Disabled Button**: A button that is non-functional.
